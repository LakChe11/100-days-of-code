# 100 Days, 100 Projects

One small coding project every day for 100 days. Mostly Python, with some C/C++ and Java along the way.

**Start:** 2026-11-12 | **Finish line:** 2027-02-19

## How it works

- One folder per day: `day-001-tip-calculator/`
- Each project has its own README (what it does, how to run it, a screenshot or GIF if visual)
- Aim for 1-2 hours per project. Small and finished beats big and abandoned.
- **Bad-day rule:** if I only have 15 minutes, I ship something tiny (a 20-line script or an improvement to an earlier project). The streak survives.
- Commit message format: `Day 12: add weather API fetch`

## Create a new day

```bash
python new_day.py 1 "tip calculator"
```

This makes `day-001-tip-calculator/` with a README and a starter `main.py`.
